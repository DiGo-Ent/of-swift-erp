5-Stage Architecture

The Proposed AI Detection Pipeline

A step-by-step walkthrough detailing how photographic leaf imagery is transformed into clinical botanical diagnoses and preventative field suggestions.

1
Stage 01

Upload / Capture Leaf Image

The user initiates the workflow by providing an optical image of a suspected leaf specimen. The system supports uploading local image files or direct real-time camera capture on smartphones or webcams in field settings.

Input Specifications
  • JPG or PNG digital image format
  • Single leaf with clear view & distinct margin
  • Captured through phone camera or webcam
  • Even, natural ambient lighting without glare
2
Stage 02

Image Preprocessing

Raw photographic inputs are mathematically preconditioned. Optical artifacts, background shadows, and variable resolution scales are standardized to ensure consistent feature extraction by the model.

How It Is Done
  • Resize to fixed dimension: 224 × 224 pixels
  • Remove sensor noise and motion blur
  • Normalize RGB pixel values into [0.0, 1.0] range
  • Optional data augmentation (rotations, flips)
3
Stage 03

AI Model Analysis (CNN)

A Convolutional Neural Network (CNN) extracts layered hierarchical features from the leaf image, scanning for subtle textural variations, chlorotic ring gradients, lesion perimeter geometry, and venation decay.

Model Engine Specs
  • Pre-trained architectures (e.g., ResNet, MobileNet)
  • Model learns patterns from healthy & diseased leaves
  • Feature maps: edge detection, color shifts, spots
  • Generates raw logit probabilities per class
4
Stage 04

Disease Classification

The network calculates a softmax probability distribution across known disease classes. The category with the highest confidence score is selected. If all probabilities are below certainty threshold, it flags as "Unknown".

Output from Model
  • Primary disease name (e.g., Early Blight)
  • Confidence percentage score (e.g., 90%)
  • Multi-class probability distribution
  • Uncertainty safeguard: flags "Unknown"
5
Stage 05

Display Result & Plant Care Information

Transforms complex machine learning classification logits into an accessible agronomic diagnostic summary, outlining pathogen causes, observed symptoms, and field-tested curative suggestions.

Information Shown
  • Predicted disease name & confidence
  • Short biological description (Alternaria solani)
  • Underlying causes & progressive symptoms
  • Basic treatment & preventive measures
